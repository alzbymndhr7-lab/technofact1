## تخيّل أنك في مطعم

أنت (**التطبيق**) تريد طعاماً من المطبخ (**الخادم**). لكنك لا تدخل المطبخ بنفسك، بل تطلب من **النادل**. النادل هنا هو الـ **API**: ينقل طلبك بطريقة متفق عليها، ويرجع لك النتيجة.

## التعريف

الـ API (واجهة برمجة التطبيقات) هي مجموعة قواعد تسمح لبرنامجين بالتواصل مع بعضهما.

## مثال عملي

هذا الكود يطلب بيانات من API ويعرض النتيجة:

```js
const res = await fetch('https://api.github.com/users/octocat');
const user = await res.json();
console.log(user.name, user.public_repos);
```

## أشهر أنواع الطلبات

| الطلب | الاستخدام |
|---|---|
| `GET` | جلب بيانات |
| `POST` | إضافة بيانات |
| `PUT` / `PATCH` | تعديل بيانات |
| `DELETE` | حذف بيانات |

عندما تفهم الـ API، ستفهم كيف تتواصل معظم التطبيقات الحديثة مع بعضها.
