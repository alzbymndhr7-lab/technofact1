If you have a ready website (HTML, CSS and JavaScript) and want to publish it to the world **for free**, GitHub Pages is one of the best options.

## Why GitHub Pages?

- **Free** for static websites.
- **Fast**, served through a CDN.
- Gives you a free address like `username.github.io`.
- You can connect your own domain like `example.com` later.

## Steps

1. Create an account on [github.com](https://github.com).
2. Create a new **Public** repository.
3. Upload your files and make sure the home page is named `index.html`.
4. Go to **Settings → Pages**, choose the `main` branch and save.
5. Wait a minute and your site link will appear.

## The simplest page

```html
<!DOCTYPE html>
<html lang="en">
  <head><meta charset="UTF-8"><title>My site</title></head>
  <body><h1>Hello world 👋</h1></body>
</html>
```

> Tip: every change you push to the repository is published automatically in about a minute.

That's all it takes to put your site in front of the whole world.
