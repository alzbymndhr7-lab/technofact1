Git هو نظام لحفظ نسخ من مشروعك وتتبّع كل تغيير فيه. إليك أهم الأوامر:

## البداية

```bash
git init                 # إنشاء مستودع جديد
git clone <url>          # نسخ مستودع موجود
```

## الحفظ

```bash
git status               # ماذا تغيّر؟
git add .                # تجهيز كل التغييرات
git commit -m "رسالة"   # حفظ نسخة
```

## المزامنة

```bash
git push                 # رفع التغييرات
git pull                 # جلب آخر التغييرات
```

## الفروع

```bash
git switch -c feature    # إنشاء فرع جديد والانتقال إليه
git merge feature        # دمج الفرع
```

> القاعدة الذهبية: اعمل `commit` صغيراً وواضحاً بعد كل خطوة.
