فاحص رسائل الاحتيال

وصلتك رسالة SMS أو واتساب أو بريد تطلب منك شيئاً؟ الصقها هنا لتكشف علامات النصب فيها قبل أن ترد أو تضغط.

الفحص يتم داخل متصفحك فقط، ولا تُرسل الرسالة لأي مكان. احذف منها أي رقم حساب أو رمز قبل لصقها إن أردت. والنتيجة تقدير يساعدك، وليست حكماً نهائياً.

    أشهر أنواع رسائل النصب

    • «رمز التحقق وصلك بالغلط»: شخص يطلب منك رمزاً وصلك برسالة. هذا الرمز مفتاح حسابك، ولا يُعطى لأحد أبداً.
    • «حسابك سيُغلق»: رسالة باسم البنك أو واتساب أو فيسبوك تستعجلك لتحديث بياناتك عبر رابط.
    • «شحنتك متوقفة»: رسالة باسم شركة توصيل تطلب رسوماً صغيرة عبر رابط، وهدفها سرقة بطاقتك.
    • «مبروك ربحت»: جائزة أو سحب لم تشارك فيه، ومطلوب منك دفع رسوم أو إرسال بياناتك.
    • «ماما هذا رقمي الجديد»: شخص يدّعي أنه قريبك ويطلب تحويل مال بسرعة. اتصل بقريبك على رقمه القديم قبل أي تحويل.
    • الاستثمار والوظائف: أرباح «مضمونة» يومية، أو وظيفة من البيت مقابل لايكات أو رسوم تسجيل.
